# 乐健体育 选课接口清单

> 来源：APK 静态分析 + 实际请求验证。服务器 `https://cpes.legym.cn/`

## 鉴权

```
Authorization: Bearer <accessToken>
Organization: <schoolId>
Content-Type: application/json
```

- accessToken 有效期约 12 小时
- **refreshToken 每次刷新都会轮换**，必须保存最新的

### 刷新 token

```
GET authorization/user/refreshToken?refreshToken=<refreshToken>
（不带 Authorization 头）
```

返回：

```json
{"code":0,"data":{"accessToken":"...","tokenType":"bearer","refreshToken":"...","accessTokenExpires":1792778769293}}
```

> 刷新后旧 token 立即失效，App 端可能需要重新登录。

## 选课相关

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `education/optional/course/project` | 项目列表（足球/篮球/太极拳…），`{semesterId}` |
| POST | `education/optional/course/time` | 上课时间段，`{semesterId,userId,year}` |
| POST | `education/optional/course/newList` | 可选课程列表，`{userId,year,semesterId}` |
| POST | `education/optional/course/optionalPageList` | 同上（分页版） |
| POST | `education/course/app/signUp` | **提交选课** |
| POST | `education/course/app/change` | 改选 |
| POST | `education/course/app/cancel` | 退课 |

### 提交选课

```
POST education/course/app/signUp
Content-Type: application/x-www-form-urlencoded

courseId=<课程id>&schoolId=<schoolId>
```

响应语义：

| code | data.state | 含义 |
|---|---|---|
| 0 | 0 或 13 | 选课成功 |
| 0 | 1 | 排队中，稍后重试 |
| 0 | 2 | 选课失败 |
| 0 | 其他 | 失败，`data.reason` 有原因 |
| 50001 | — | 当前选课人数过多，重试 |

### 当前学期

```
GET education/semester/getCurrent
→ {"yearRange":"2026-2027","weekIndex":9,"id":"8a97802f..."}
```

## 学生课表（冲突检测用）

```
GET education/course/app/forStudent/list?userId=<id>&semesterId=<id>
```

返回示例：

```json
{"code":0,"data":[{
  "id":"8a978030a023028501a0383fa10c11af",
  "name":"成都校区-趣味田径-2025-周天一-周一14:00~15:35",
  "weekLabel":"周一","timeStr":"14:00~15:35",
  "courseStatusStr":"进行中"
}]}
```

**注意**：这个接口只返回体育课，不含专业课表。
必修课时间需要用户在 `config.json` 的 `busy_slots` 里手填。

### 时段解析陷阱

课程名 `周天一-周一14:00~15:35` 里有两个「周X」。
必须把星期和紧随的时段**绑在一起**匹配，否则会把 `周天一` 误判成周日。

## 尚无会员概念

全量扫描 APK 的 `app-service.js`：

| 关键字 | 命中 |
|---|---|
| `会员` / `VIP` / `vip` / `member` / `Member` | 0 |
| userInfo 里的会员类字段 | 无（24 个字段全部为常规字段） |

结论：**会员制不在 App 层**，是学校规则层面的差异，客户端无法自动识别。
工具因此改用「盯窗口」模式（见下），不依赖固定的开抢时刻。
