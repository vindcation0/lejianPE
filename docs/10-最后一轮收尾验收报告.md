## 4. 网络隔离验收

通过 [`tests/network_guard.py`](file:///c:/Users/vindacation/Documents/deepseek-harness/lejianPE/tests/network_guard.py) 与专项测试套件 [`tests/test_network_guard.py`](file:///c:/Users/vindacation/Documents/deepseek-harness/lejianPE/tests/test_network_guard.py)（N01～N07）完成验证：

### 4.1 隔离屏障机制
- **拦截层级**：覆盖 `socket.socket.connect`、`socket.create_connection`、`socket.getaddrinfo`，以及针对本地代理隧道的 `http.client.HTTPConnection.connect` 和 `request`。
- **DNS 前置拦截**：在发起系统底层 DNS 查询前立即阻断外部域名（如 `cpes.legym.cn`），杜绝 DNS 外发风险。
- **代理穿透拦截**：即使系统配置了本地代理，试图代理请求外部域名或公网 IP 时依然在 HTTP 客户端层被强制阻断。

### 4.2 网络访问判定测试矩阵
| 用例编号 | 访问目标 | 通信方式 | 预期行为 | 实测结果 |

| **N01** | `127.0.0.1` | 原生 TCP Socket | 允许通信（接收到 `OK_LOCAL`） | **PASS** |
| **N02** | `localhost` | 原生 TCP Socket | 允许通信（接收到 `OK_LOCAL`） | **PASS** |
| **N03** | `::1` | IPv6 回环解析 | 允许放行（`getaddrinfo` 成功） | **PASS** |
| **N04** | `8.8.8.8:53` | 公网 IP TCP | **阻断**（抛出 `RuntimeError`） | **PASS** |
| **N05** | `cpes.legym.cn` | 外部域名解析 | **阻断**（解析前抛出 `RuntimeError`） | **PASS** |
| **N06** | 本地服务 | `urllib.request` | 允许访问（HTTP 200 返回 `OK_LOCAL`） | **PASS** |
| **N07** | 乐健外部接口 | `urllib.request` | **阻断**（建立连接前抛出 `RuntimeError`） | **PASS** |
