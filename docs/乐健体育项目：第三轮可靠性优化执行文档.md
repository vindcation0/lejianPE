# 三、任务一：UNKNOWN 安全屏障

**优先级：最高，必须首先完成。**

## 3.1 当前问题

目前程序在报名提交后，如果发生：

- 请求超时。
- HTTP 503。
- HTTP 504。
- 连接中断。
- 无法解析服务端响应。
- 其他无法确定报名结果的异常。

会将该次报名标记为 UNKNOWN。

但是当前流程仍然可能继续处理下一个候选活动。

这会产生以下风险：

```
提交候选 A
    ↓
请求超时
    ↓
A 实际可能已经报名成功
    ↓
本地标记 UNKNOWN
    ↓
继续提交候选 B
    ↓
B 也可能报名成功
    ↓
继续提交候选 C
```

程序无法确定 A、B 是否已经占用报名名额。

因此必须建立全局安全屏障。
