## 二、M0 阶段：现有认证代码梳理与复用策略

### 2.1 现有核心模块职责与能力盘点

1. **`core/auth_error.py`**：
   - 包含面向异常类型的继承树：`AuthError`、`CredentialError`、`InvalidCredentialError`、`BusinessAuthError`、`TokenAcquisitionError`、`SchoolInfoError`、`SemesterInfoError`、`AuthNetworkError`。
   - **复用决策**：保持既有异常类定义 100% 向后兼容，作为错误诊断器的输入来源。

2. **`core/credential_storage.py`**：
   - 负责凭据 `credential.json` 的存储与加载。
   - 包含 Windows DPAPI 加解密、Fail-closed 安全屏障、原子替换、以及脱敏工具 `mask_account` 与 `mask_secret`。
   - **复用决策**：直接复用其加解密逻辑和基础脱敏能力。

3. **`core/auth_manager.py`**：
   - 负责 AES-128-CBC 信封打包与发送、HTTP 状态与业务码解析、学期拉取及 `state.json` 原子保存。
   - **复用决策**：保持 `login()` 与 `save_state_atomically()` 的业务与校验逻辑不变，由上层捕获异常后统一接入诊断器。

4. **`tools/login_envelope.py`**：
   - 负责 AES 登录信封的 `wrap` 与 `unwrap`。
   - **复用决策**：完全复用，不做修改。

5. **`tools/capture_login.py`**：
   - 负责与 Android 模拟器通信、注入证书、透明代理抓包与签名提取。
   - **复用决策**：保持独立可用，为后续 M2 一键重新初始化提供基础。

6. **`tools/login_cli.py`**：
   - 命令行密码登录入口。
   - **改动范围**：接入 `handle_login_failure`，在凭据加载、登录认证、会话落地出错时统一输出诊断报告。

## 三、M1 关键修正与细化（四大改进点）

在基础 M1 诊断功能完成后，针对实际认证协议边界和安全策略进行了四项重要优化：

### 3.1 修正一：HTTP 401 细粒度区分（登录接口 401 vs 业务接口 401）
- **问题**：此前将所有 HTTP 401 笼统视为 `TOKEN_EXPIRED`，但登录接口尚未产生 Token，401 代表账号认证未通过或无访问权限。
- **改进**：
  - **登录接口 401 (`UNAUTHORIZED`)**：判断依据为处于登录阶段或登录路径。明确提示“登录凭据无效或未授权”，分析账号被锁定、尚未激活或未在学校系统开通等可能，提示先在 App 验证账号，`can_reinit = False`。
  - **业务接口 401 (`TOKEN_EXPIRED`)**：处于业务上下文（如 `getCurrent`、活动接口），明确提示“访问令牌 (AccessToken) 已过期或已被作废”，引导重新登录以获取新 Token，`can_retry = True`。

### 3.2 修正二：严控重新初始化推荐矩阵（`UNKNOWN_ERROR` 绝不盲目引导重抓）
- **问题**：此前 `UNKNOWN_ERROR` 默认 `can_reinit = True`，在服务端故障或非标报错时误导用户重新抓包。
- **改进**：严格按照策略矩阵设定：
  - **推荐重新初始化 (`can_reinit = True`)**：仅限 `SIGNATURE_ERROR`（50004 签名失效）、`CREDENTIAL_CORRUPTED`（本地凭据损坏/缺失）、`DPAPI_DECRYPT_FAILED`（当前 Windows 账号无权解密需重新专属加密）。
  - **不推荐重新初始化 (`can_reinit = False`)**：
    - `WRONG_PASSWORD`：核对密码输入，禁止重抓。
    - `NETWORK_ERROR`：网络通信故障，禁止重抓。
    - `SERVER_ERROR`：服务端故障，稍后重试，禁止重抓。
    - `RATE_LIMITED`：服务端限流，禁止重抓。
    - `UNKNOWN_ERROR`：**严格设为 False！** 先提供脱敏诊断信息排查，绝不默认引导重抓签名。

### 3.3 修正三：坚持 Fail-closed 安全策略，坚决拒绝明文降级
- **问题**：此前提示中存在“非 Windows 下切明文模式”的表述，违背 Fail-closed 凭据保护原则。
- **改进**：
  - 彻底剔除所有“切明文模式”建议。
  - **`DPAPI_UNAVAILABLE`**：非 Windows 环境提示缺乏原生 DPAPI 安全隔离，明确告知系统遵循 Fail-closed 屏障，严禁在不支持安全加密的平台降级保存明文凭据；如需非 Windows 部署应配置 Keyring 或专属密钥库，`can_reinit = False`。
  - **`DPAPI_DECRYPT_FAILED`**：Windows 下解密失败（跨用户或密文损坏），提示在当前登录用户重新初始化生成专属凭据，原有凭据受保护不被破坏，`can_reinit = True`。

### 3.4 修正四：HTTP 429 独立分类并支持 Retry-After 冷却策略
- **问题**：429 服务端限流此前被混在普通 4xx 参数错误中。
- **改进**：
  - 独立分类为 **`RATE_LIMITED`**。
  - **解析 Retry-After**：若服务端响应或上下文中包含 `Retry-After`，精确提取并提示用户冷却等待特定秒数。
  - **保守等待策略**：若未包含 `Retry-After`，提示采用保守等待策略（建议暂停 60~180 秒）。
  - **禁止连续重试**：`can_retry = False`，明确警告用户暂停操作，严禁自动连续重试，防止 IP 遭受更长时间封禁。

## 四、统一错误分类映射矩阵（最新版本）

| 错误分类 (`ErrorCategory`) | 判断依据 / 触发源 | 用户提示摘要 | 建议操作 | 是否推荐重初始化 (`can_reinit`) | 是否允许重试 (`can_retry`) |
| :--- | :--- | :--- | :--- | :---: | :---: |
| **`SIGNATURE_ERROR`** | 服务端业务码 `50004` 或签名校验失败 | 客户端提供的登录签名校验失败 | 引导重新初始化认证凭据（主菜单 `[b]`） | **是** | 否 |
| **`CREDENTIAL_CORRUPTED`** | 本地 `credential.json` 缺失、非合法 JSON 或缺少必要字段 | 本地认证凭据缺失、损坏或不完整 | 引导重新执行初始化生成凭据 | **是** | 否 |
| **`DPAPI_DECRYPT_FAILED`** | Windows 下由于跨用户或密文损坏解密失败 | Windows DPAPI 凭据解密失败 | 当前 Windows 用户下重新初始化生成专属凭据 | **是** | 否 |
| **`WRONG_PASSWORD`** | 明确返回密码错误、账号错误或业务码 10001/10002 | 账号或密码不正确 | 核对账号密码，重新输入 | **否** | **是** |
| **`UNAUTHORIZED`** | 登录接口返回 HTTP 401 | 账号登录凭据未通过服务端核验 | 检查 App 端登录与教务学籍开通状态 | **否** | 否 |
| **`TOKEN_EXPIRED`** | 业务接口返回 HTTP 401 | 当前访问令牌 (AccessToken) 已过期或作废 | 重新执行命令行登录获取新 Token | **否** | **是** |
| **`REFRESH_TOKEN_EXPIRED`**| 刷新接口拒绝或 RefreshToken 过期 | 长期刷新凭据失效，无法自动刷新 | 重新执行账号密码登录 | **否** | **是** |
| **`RATE_LIMITED`** | HTTP 429 服务端限流信号 | 服务端触发频控限流保护 | 按 Retry-After 冷却等待，严禁连续重试 | **否** | 否 |
| **`NETWORK_ERROR`** | DNS 失败、连接超时 (TimeoutError)、断网 | 无法建立与乐健服务器的网络通信连接 | 检查本地网络与系统代理设置后重试 | **否** | **是** |
| **`SERVER_ERROR`** | HTTP 500 / 502 / 503 / 504 服务端故障 | 乐健服务端基础设施出现异常 (HTTP 5xx) | 服务端维护中，建议稍后重试 | **否** | **是** |
| **`CLIENT_PARAM_ERROR`** | HTTP 4xx (非 401/429) 请求参数错误或拒绝 | 客户端请求参数有误或 IP 受策略限制 | 检查网络配置或查看最新更新说明 | **否** | 否 |
| **`DECRYPT_FAILED`** | AES 登录信封 (pyd) 解密失败 | 服务端返回的加密载荷解密失败 | 检查本地北京时间同步，保存报告反馈 | **否** | **是** |
| **`MALFORMED_RESPONSE`** | 缺少必要字段 (`accessToken`/`schoolId`/`data`) | 服务端响应格式非法或缺失必要字段 | 系统已阻止残损会话落地，保护原会话 | **否** | 否 |
| **`DPAPI_UNAVAILABLE`** | 当前平台非 Windows 不支持 DPAPI | 平台不支持 Windows DPAPI 安全加密体系 | Fail-closed 拒绝明文降级，提示平台限制 | **否** | 否 |
| **`UNKNOWN_ERROR`** | 无法归类的未知非标异常 | 登录过程遇到未分类的未知异常 | 提供脱敏诊断报告，先排查不盲目重抓 | **否** | 否 |
